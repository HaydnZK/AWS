# Project Build Documentation & Artifacts
This folder contains the complete visual step-by-step documentation for building the honeypot infrastructure from scratch. Keeping these images isolated here prevents the main repository from getting cluttered.

Inside, you'll find:
* **Infrastructure Setup:** Comprehensive screenshots capturing the entire end-to-end installation, service configuration, and system hardening process.
* **Network & Cloud Monitoring:** Visual verification of the AWS network configuration, private endpoint setup, and successful CloudWatch pipeline validation.
* **Live Telemetry:** The final captures showing the active defense infrastructure working in real time, including the post-quantum cryptographic handshake logs.
